# avalia-app-releases

APKs de preview do app Avalia, da Secretaria Municipal de Educação de Muriaé.

**Página de instalação:** https://secretaria-municipal-de-educacao-muriae.github.io/avalia-app-releases/

O app instalado e a página leem a **última release publicada** deste repositório:

- o app compara a tag com a versão dele e, se a da release for maior, oferece atualizar;
- a página usa o APK da última release no botão "Baixar o app".

## Publicar uma versão

Uma release por versão:

- tag igual à versão do app, com `v` (ex.: `v1.11.0`);
- o APK anexado, com nome terminando em `.apk`;
- a descrição vira as "novidades" no app e na página;
- publicada: rascunho e pré-release são ignorados.
